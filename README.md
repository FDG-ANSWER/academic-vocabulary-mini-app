# Academic Vocabulary Mini-App

## Product Goal

Provide university students with a simple, accessible and privacy-respecting web application for learning academic vocabulary and checking their understanding through an interactive quiz.

## Intended Users

The intended users are university students, particularly students who are developing academic English skills and need to understand vocabulary commonly used in academic reading and writing.

## Features

- Landing page explaining the purpose of the application
- Clear instructions for users
- Learning section with eight academic vocabulary items
- Meaning and example sentence for each item
- Six-question vocabulary quiz
- Immediate feedback for correct and incorrect answers
- Progress indicator and final score
- Retry quiz option
- Keyboard-accessible navigation
- No login, database, tracking or collection of personal information

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run the Application

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No installation, account, database or back-end service is required.

## Privacy

This application does not collect, store or transmit personal information. It does not require a user account and does not use analytics or tracking services.
