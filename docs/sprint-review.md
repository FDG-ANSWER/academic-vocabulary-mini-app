# Sprint Review

## Sprint Goal

Deliver a usable and tested Academic Vocabulary Mini-App with academic vocabulary learning content and a six-question quiz that provides feedback, a final score and retry support.

## Completed

- Landing page explaining the application purpose.
- Clear user instructions.
- Home, Learn and Quiz navigation.
- Eight academic vocabulary items, each with a meaning and example sentence.
- Six-question multiple-choice vocabulary quiz.
- Feedback for correct, incorrect and unanswered questions.
- Correct-answer highlighting and short explanations.
- Final score displayed out of six.
- Retry quiz option that clears previous answers and feedback.
- Basic accessibility measures including labelled controls, keyboard navigation, focus handling and live feedback.
- Privacy approach with no account, database, analytics, tracking or collection of personal information.

## Not Completed

The following items were intentionally outside this sprint scope:

- User accounts and login.
- Database or back-end service.
- Content-management system.
- Saving quiz progress or scores.
- Random question order and a larger question bank.
- Formal usability testing with students or assistive-technology users.

## Strengths

- The application focuses on the core learning workflow.
- Navigation and instructions are clear.
- Learners receive actionable feedback rather than only a score.
- The app works without a backend and does not collect personal information.
- The implementation uses simple HTML, CSS and JavaScript, making it easy to review and maintain.

## Limitations

- Vocabulary content and the quiz question bank are limited.
- Results are not saved between browser sessions.
- Questions are not randomised.
- Accessibility checks were manual and did not include formal testing with assistive-technology users.

## Next Steps

- Add more vocabulary categories and quiz questions.
- Randomise questions and answer order.
- Conduct usability testing with representative university students.
- Perform more detailed accessibility testing, including screen-reader testing.
- Consider optional local-only progress storage after assessing privacy implications.
