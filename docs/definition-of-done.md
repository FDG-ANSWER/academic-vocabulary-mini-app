# Definition of Done

A backlog item is Done only when all relevant conditions below have been met:

- Its acceptance criteria have been met.
- The feature works in a current modern web browser.
- The feature has been manually tested and the result recorded where appropriate.
- No major JavaScript errors appear in the browser console during the tested workflow.
- The feature can be reached and operated using a keyboard where applicable.
- Semantic HTML, labels and accessible feedback have been considered.
- The layout remains readable and usable at desktop and narrow mobile-sized viewport widths.
- The feature does not collect, store or transmit personal information.
- Related source code and documentation are saved, committed and pushed to GitHub.
- The related GitHub Project item is moved to Done only after testing has passed.

For the final sprint increment, Done additionally requires:

- The application contains at least eight vocabulary items.
- The quiz contains at least six questions.
- Feedback, explanations, final score and retry function work.
- The README and required Agile documents are complete.
- The GitHub Pages deployment has been checked.
