# AI Use Statement

Generative AI was used as a learning, planning and drafting aid during this project. It was used to help:

- break down the assessment requirements into a recovery sprint plan;
- propose an initial structure for project documentation;
- explain HTML, CSS and JavaScript concepts;
- suggest possible test cases and accessibility checks;
- review wording for documentation.

All generated suggestions were reviewed, adapted and tested by the student before use. The student remains responsible for understanding, explaining and maintaining all submitted code and written work.

No AI-generated content has been included without review. The final implementation, testing decisions and repository activity reflect the student's own work during the assessment period.

Tool used: ChatGPT (OpenAI).

This statement will be updated if further AI assistance is used for specific code, documentation or debugging tasks.
